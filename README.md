# منصة نور الهدى | Noor Al-Huda Platform

![Noor Al-Huda Logo](public/logo-share.png)

## 🌟 عن المشروع
**نور الهدى** هي منصة إسلامية متكاملة تهدف إلى نشر آداب الإسلام وتعزيز الوعي الديني بين المسلمين. يسعى المشروع إلى جمع الأمة الإسلامية على كلمة سواء وتوفير الأدوات الروحانية والعلمية التي تعين المسلم في حياته اليومية.

## 🎯 الأهداف
- نشر العلم النافع والوعي الديني والشرعي.
- تعزيز قيم آداب الإسلام في التعاملات اليومية.
- خلق بيئة تفاعلية للمجتمع المسلم لتبادل المعرفة.
- توفير مصادر دينية موثوقة (قرآن، أذكار، كتب).

## ✨ مميزات المنصة

### 📖 القرآن الكريم وعلومه
- **تلاوة واستماع:** تصفح السور مع إمكانية التبديل بين **وضع القراءة** المريح للعين و **وضع الاستماع** لتلاوات خاشعة بأصوات أشهر القراء.
- **إذاعة القرآن:** بث مباشر لإذاعات القرآن الكريم تعمل في الخلفية أثناء تصفحك للموقع.
- **المكتبة الإسلامية:** قسم خاص للكتب الدينية والمصادر التعليمية.

### 🤝 المجتمع والتفاعل
- **الملف الشخصي المتطور:** إمكانية تعديل البيانات الشخصية، ومتابعة **منشوراتك** و **أسئلتك** الخاصة في مكان واحد.
- **المنشورات:** مساحة لمشاركة الفوائد والخواطر الدينية مع المجتمع.
- **شارك علمك (الأسئلة والأجوبة):** منصة تتيح للمستخدمين نشر الوعي الديني من خلال إضافة "سؤال وإجابة" لتنبيه الغافلين وتعليم الناس. تخضع جميع الأسئلة للمراجعة من قبل الإدارة (Admin) للموافقة أو الرفض قبل النشر لضمان دقة المعلومات الشرعية.

### ⚖️ المركز القانوني والمساعدة
- **سياسة الخصوصية:** توضيح كامل لكيفية حماية بيانات المستخدمين.
- **شروط الاستخدام:** بيان الحقوق والواجبات لضمان بيئة آمنة للجميع.
- **مركز المساعدة:** دليلك الشامل لفهم قوانين المجتمع وكيفية المشاركة الفعالة.

### 📿 أدوات المسلم اليومية
- **الأذكار:** قسم متكامل لأذكار الصباح والمساء وأذكار المسلم اليومية.
- **مواقيت الصلاة:** تتبع دقيق لمواقيت الصلاة حسب الموقع الجغرافي.

## 🛠️ التقنيات المستخدمة
- **Next.js 16 (App Router)**
- **TypeScript**
- **Tailwind CSS**
- **Axios** (للتواصل مع API)
- **Swiper.js** (للعناصر التفاعلية)
- **React Icons**

## 🚀 التشغيل المحلي

1. قم بتحميل المستودع:
   ```bash
   git clone https://github.com/your-username/noor-alhuda.git
   ```

2. انتقل إلى مجلد المشروع:
   ```bash
   cd my-app
   ```

3. قم بتثبيت المكتبات:
   ```bash
   npm install
   ```

4. ابدأ تشغيل المشروع:
   ```bash
   npm run dev
   ```
